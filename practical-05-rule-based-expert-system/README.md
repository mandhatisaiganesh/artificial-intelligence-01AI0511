# Practical 05 — Rule-Based Expert System

> **Medical Advisory with Forward & Backward Chaining**
> AI Pillar: Symbolic Knowledge & Planning

## Objective

Build a rule-based expert system with forward chaining (data-driven), backward chaining (goal-driven), and an explanation facility for medical symptom diagnosis.

## Key Concepts

`Production Rules` · `Forward Chaining` · `Backward Chaining` · `Explanation Facility` · `Knowledge Base`

## Experimental Results

- Forward chaining derives all reachable conclusions from given symptoms.
- Backward chaining proves goal-directed queries with a full audit trail.
- Three test cases demonstrate influenza, common cold, and measles pathways.

> **Disclaimer:** This is a toy educational system, not medical advice.
