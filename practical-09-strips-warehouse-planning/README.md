# Practical 09 — STRIPS Planning & Goal-Stack Planner

> **Blocks World Automated Planning**
> AI Pillar: Symbolic Knowledge & Planning

## Objective

Implement STRIPS operator representation (preconditions, add list, delete list) and goal-stack planning for the Blocks World domain. Generate valid action sequences from initial to goal configurations.

## Key Concepts

`STRIPS Representation` · `Goal-Stack Planning` · `Preconditions/Effects` · `Blocks World` · `Automated Planning`

## Experimental Results

- Plans generated for multi-block rearrangements (e.g., C-on-A → A-on-B, B-on-C).
- Correct precondition/effect tracking throughout the plan.
- Goal satisfaction verified against final state.
