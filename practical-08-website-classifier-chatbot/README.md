# Practical 08 — Text Classification & Explainability

> **Spam/Ham Classifier with Ethics Report**
> AI Pillar: Applied NLP & Responsible AI

## Objective

Build a Naive Bayes text classifier for spam detection with per-prediction explainability (top contributing words via log-likelihood ratios) and an ethics/fairness/privacy report.

## Key Concepts

`Text Classification` · `Bag-of-Words` · `Log-Likelihood Ratios` · `Explainability` · `AI Ethics`

## Experimental Results

- 4/4 accuracy on toy test set.
- Per-prediction explanations show top-3 discriminative words with log-odds contributions.
- Ethics report addresses fairness, privacy, safety, and limitations of bag-of-words models.
